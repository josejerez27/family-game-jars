# Family Game Jars

Three installable, offline-capable web apps (PWAs), plain HTML/JS, no build step.

- `/bored-jar/`: Hi Bored, I'm Dad 4.0 (everyday ideas + game kits)
- `/christmas/`: Christmas Game Jar
- `/baby-shower/`: Baby Shower Game Jar

Hosted on GitHub Pages. To update an app: edit its files, bump `CACHE` in that app's `sw.js`, commit and push.
